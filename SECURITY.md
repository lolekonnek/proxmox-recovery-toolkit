# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of Proxmox Recovery Toolkit.

| Version | Supported |
| ------- | --------- |
| Latest stable release | :white_check_mark: |
| Development builds | :x: |
| Older releases | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in Proxmox Recovery Toolkit, please report it responsibly.

**Please do not disclose security vulnerabilities through public GitHub Issues.**

Instead, use GitHub's private vulnerability reporting feature:

1. Open the repository on GitHub.
2. Navigate to the **Security** tab.
3. Select **Report a vulnerability**.
4. Provide a detailed description of the issue.

### What to Include

When reporting a vulnerability, please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Affected versions.
- Relevant logs or screenshots, if applicable.

### Response Process

- Reports will be reviewed as soon as possible.
- The reporter will receive an acknowledgment when the report is reviewed.
- Valid vulnerabilities will be investigated and addressed.
- Security fixes will be included in a future release.
- If a report is declined, an explanation will be provided whenever possible.

### Responsible Disclosure

Please allow the maintainers reasonable time to investigate and fix reported vulnerabilities before publicly disclosing them.

Thank you for helping keep Proxmox Recovery Toolkit secure.
